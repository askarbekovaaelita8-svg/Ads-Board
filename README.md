# Доска объявлений

Учебное React-приложение для просмотра и публикации объявлений через настоящий backend API.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Проект собирается Vite без Babel и публикуется на GitHub Pages workflow `.github/workflows/deploy.yml` из ветки `main`. В GitHub Actions base-путь берётся из имени репозитория автоматически.
